## 🚀 Key Features

- **Modern Tech-Inspired Aesthetic:** Clean deep navy (`#070b14`), electric blue (`#0284c7`, `#38bdf8`), and cyan (`#06b6d4`, `#22d3ee`) color palette with glassmorphism card effects.
- **Real Business Photography & Videos:** Integrated 18 authentic shop photographs, workbench repairs, curved AMOLED display curing, and diagnostic videos.
- **Interactive Lightbox Gallery:** Filterable portfolio (All, Repairs & Process, Completed Work, Shop & Setup) with keyboard-navigable fullscreen modal.
- **Repair Video Showcase:** Dedicated smartphone video showcase featuring real before-and-after display repairs, touchscreen testing, and optical fingerprint verification.
- **Direct Communication:** Instant one-click phone calling (`tel:`), prefilled WhatsApp messaging, and Google Maps direction links.
- **Mobile First & Fully Responsive:** Seamless experience across smartphones, tablets, laptops, and desktop screens.
- **SEO & Schema Markup:** Includes Open Graph metadata, semantic HTML5, and valid `LocalBusiness` JSON-LD structured data.

## 💻 Commands to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The site will run at `http://localhost:3000` (or `http://localhost:5173`).

### 3. Build for Production
```bash
npm run build
```
Generates production-ready static assets in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
Runs the local static server to preview the compiled build.
